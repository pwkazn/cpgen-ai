# 本地 Web UI example

本目录保存用户已确认的直角、高密度工作台原型，作为 UI 实现输入。它是设计参照，不是已连接 Go/Gin 后端的产品。

## 打开

直接用浏览器打开 [index.html](index.html)。也可以在仓库根目录执行：

```powershell
python -m http.server 8081 --bind 127.0.0.1 --directory docs/design/examples/local-web-ui
```

然后访问 `http://127.0.0.1:8081/`。示例服务仅用于预览；产品入口按设计使用 `cpgen serve`。

## 文件

- `workbench.fragment.html`：可编辑原型源文件，包含界面结构、CSS 和演示交互。
- `index.html`：可独立打开的预览，包含预览外壳和源文件副本。修改原型源文件后需重新生成预览，避免两份内容漂移。

预览由原型渲染工具生成；后续更新可以使用创建该原型的 visualize 导出流程。该工具不是产品构建依赖。没有该工具时仍可直接打开已提交的 index.html，并读取源文件复用界面。

## 实现时如何使用

先浏览任务详情、任务列表、新建题目、待评审、受阻与环境配置页面，再阅读 [具体设计](../../local-web-ui.md)。保留顶部导航、矩形标签、连续分区、正文与右侧摘要、紧凑控件和浅深色样式。可从源文件提取 HTML/CSS，拆为产品页面与组件，无需从零重画。

必须替换示例任务、固定预算和报告、演示提示、内存状态及模拟提交，接入真实 API。生产代码不依赖预览外壳、`window.openai`、Tweak 或宿主图标初始化；相关能力以普通前端状态和本地资源替代。预览外壳可能引用公共 CDN 资源，不能直接作为产品的离线静态构建产物。

业务状态、并发与资源归属、接口和验收以设计文档为准。特别是取消原因、评审版本校验、实际下载和容量拒绝，原型尚未完整实现。无需为了保留 example 而保留其演示限制。

验收时对照相同页面与宽度：直角布局、分隔线、间距、文字密度、主要操作位置保持一致；新增真实功能沿用相同视觉语言。
